THICC TOOL 004 — CACHE Y NOTIFICACIONES

Analyze: usa caché válida. Force analyze: ignora ambas cachés nuevas y la caché
original de perfiles de superficie; realiza un diagnóstico nuevo.
Analyze library / Force analyze library: modo equivalente para la biblioteca;
una notificación sonora y visual al final del lote.

Archivos nuevos por mod:
- thicc_detection_cache.json: evidencias normalizadas, detalles reportados por
  los detectores de 002, puntuaciones, contribuciones y consola de detección.
- thicc_analysis_cache.json: resultado completo de diagnose, incluyendo partes,
  roles efectivos, cfg, draw_meta, landmarks, natural, altura, estado de
  esqueleto, advertencias, evidencias y consola capturada.
Ambos JSON tienen esquema, hash de integridad y escritura atómica. No contienen
pickle. El pickle temporal del worker original se mantiene para IPC local.

SHA-256: detectors_hash (módulos de detección, código de carga y dependencias),
classifier_hash (WEIGHTS y classify_part), mesh_hash (Position.buf.orig o
Position.buf, Index.buf, Blend.buf, BlendRemapVertexVG.buf y el INI activo).
analysis_hash y config_hash validan la instantánea completa. Un cambio de pesos
reutiliza las evidencias normalizadas; un cambio de normalización puede requerir
repetir detectores. Se usa el INI completo conservadoramente: incluso cambios
 de visibilidad pueden invalidar caché. Las texturas y los buffers de salida
no intervienen. Cambios de cfg invalidan solo la instantánea completa.
Los errores de detectores por componente impiden guardar una nueva instantánea;
una anatomía incompleta normal puede guardarse con ready=False y sus advertencias.
El popup distingue Real analysis, FULL CACHE, DETECTION CACHE + new morphology,
y CACHED DETECTORS + new classification. Verde para resultados reutilizados.
En Windows se usa winsound.MessageBeep; fallback QApplication.beep.
No se modificaron los pesos, algoritmo de deformación, ni el visor 3D.

Pruebas sintéticas: real 4.133 s / full hit 0.051 s, dump idéntico salvo aviso
nuevo de caché. Config modificada: detection hit. Force: detection miss.
Cambio temporal de pesos: se comprobó entrada en rama de reclasificación; no
se completó esa prueba de integración; pesos originales restaurados.
