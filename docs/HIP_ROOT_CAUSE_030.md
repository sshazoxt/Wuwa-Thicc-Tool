# Patch 030 — Hip root cause diagnostics (requires 029)

Experiment-only patch. No production Python files are changed. All runs use a private model snapshot and dry mode; backups created by the engine are in the disposable copy. The normal smoothing options remain installed and unchanged. The cases disable coupled hip-thigh, relative silhouette, thigh rounding, displacement smoothing, inner fill, advanced clothing, final regularization, Seam Guard, Belly and experimental Waist. The original calibration's internal correction kernel is deliberately retained: changing it would confound the diagnosis. Arm/frozen protections and saved roles remain in effect. The saved Legacy/Continuous field mode and manual landmarks are retained and logged.

Use the existing Experiments workspace, Refresh, select 34–40 and Run automated. For comparable results across mods, save the same Hips value (prefer 3.98 initially), field mode, and equivalent correctly assigned Skin/Anatomy roles. Run on the affected segmented Suoming and on a known-good model with a single continuous pelvis/torso or full body. The scripts read saved settings, not unsaved slider changes. Hips only unless specifically testing Thighs. All cases use the original buffer as baseline. 34 includes a fixed sweep and 39 uses Thighs 2.0. If Hips is unset or zero, the isolated comparisons use 3.98.

- 34: sweep Fixed Core, Hips 0/1/1.5/1.75/2/3/5 plus saved value. No change to production calibration.
- 35: compare Hc caps 6/9/12/18 in reference cm. Report actual post-final-iteration residual, cap hits, raw field contributions and contour change. Larger caps are experimental, not a recommended fix.
- 36: per-draw geometric overlap, exact-to-quantization triangle duplicate count, original/deformed section widths, nearest-vertex displacement differences and optional area-weighted sampled point-to-triangle proximity; compare all Skin, duplicate-face removed, active Skin, active Skin with duplicates removed in the calibration reference only. Controlled partition of exactly the same faces tests order invariance, not physical seam topology. The geometry and roles being moved never change. Active comparisons require resolved Skin draws.
- 37: run the exact archived 021 main engine source alongside the installed engine and compare output vertex by vertex, roles, reference triangles and measurements. The archived engine uses installed dependencies, not a complete historical environment. This is a main-engine regression test, not a proof that all dependencies have stayed unchanged.
- 38: probe the actual outline's response to a one-unit correction and estimate the required correction per section; compare fixed cap vs response-based cap and response-scaled update. Experimental cap bounds 6–24 and update bounds 0.5–4 are diagnostic safeguards, not validated production settings. The estimate is local, not a guarantee of reaching a nonlinear envelope.
- 39: Thighs only with/without calibrated hip contribution, Hips only, combined. Note that the production target depends on Thighs even if Hips is zero.
- 40: active reference and active deduplicated reference introduced earlier, at the measurement surface stage before measure(), fit_axis(), root fitting and calibration. Retains saved roles, original vertex IDs, skeleton/anatomy selection and pre-measurement arm classification. This isolates the measured surface reference, not the entire upstream detector. Manual landmark overrides may mask changes in effective landmarks; natural and effective values are logged. Temporary source clone in the experiment process is restored on exit.

All visualizations use the shared ExperimentViewer and support batch capture with 029. Final output records experiment number and name. Section widths and sampled second differences are geometric diagnostics, not guarantees of contour smoothness. Near-vertex and sampled surface distances do not prove triangle intersection; duplicate faces use coordinate quantization, not topology welding. Report actual residual and visible shape together. High caps are not applied to real mods. Direction changes/area compression counters do not constitute complete collision or inversion validation.

New tests: geometric deduplication, partition invariance, configuration preservation, scoped calibration override, response probe, temporary engine clone, archived source compilation and triangle membership. Real mod buffers and Windows/PyVista rendering are not available for validation here.
