# Anatomical Reconstruction Fallback — diagnostic test 008

- Full Body (virtual) is a read-only Wardrobe row. It assembles resolved default INI draws, including hair, face, garments and accessories, regardless of whether the game is running. It never enters role, anatomy, label or visibility configuration. Hidden/commented draws stay hidden.
- Offline interpretation supports scalar constants, simple assignments, nested if/elif/else, Present and local CommandLists. Standard WWMI readiness guards are assumed ready. Unknown conditions exclude uncertain draws. Duplicate section headers are accepted. GPU shaders, external CommandLists, dynamic game state, persisted in-game toggles and alternative resource buffers are not emulated. Full Body is a best-effort view, not a guarantee of an exact in-game render.
- ARF is called once on the existing diagnostic return path, after weighted classification and morphology diagnostics. It only performs regional analysis if automatic Skin lacks lower-body coverage. Coverage uses provisional normalized Z bands and left/right sampling, with optional unified-bone segmentation. It is not a validated anatomical segmentation or skin-material detector. The default reference may include garments. Nearest-vertex overlap and Naming are reported as evidence; self-matches are explicitly marked. No roles, anatomy, scores, buffers or existing deformation decisions are changed by ARF. No new blocking rule is added.
- Preview returns the exact computed float32 positions to the GUI through the existing temporary worker result. The GUI automatically selects Full Body and Comparison after Preview/Apply. Current reads the on-disk buffer; Preview displays the last computed preview; Comparison/Displacement use the last preview when available, otherwise current. Restore and reanalysis clear the preview. The existing backup behavior is unchanged. Preview does not replace geometry buffers.
- Full-analysis caching already hashes the new Python module; detector cache remains unchanged by ARF. Full cache hits replay the diagnostic log. Force analyze reruns the diagnostic. No separate ARF cache in this test.
