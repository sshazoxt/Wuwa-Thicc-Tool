# Conditional ARF integration
ARF runs once per engine invocation after weighted detection and before effective roles and anatomy. Full Body reconstruction remains available in diagnostics regardless of the coverage gate. If all five provisional lower-body bands have automatic Skin coverage, no recovery is attempted. Recovery is restricted to ambiguous/unresolved lower-body candidates with positive naming, >=60% lower-body overlap, >=75% near-reference vertices, a complete preferred reference, no legacy topology veto, resolved INI state and no manual role or Frozen protection. Candidates must improve missing coverage. Scores and detector evidence remain unchanged. Saved anatomy remains authoritative; reset automatic to test on previously saved role lists. The GUI shows ARF provenance in the role tooltip. Preview and Apply use the same recovery path. Existing analysis cache hashes include the changed Python files. This is a heuristic, not proof of material; active reference members can match themselves. Full-body segmentation and missing-leg blocking remain future work. Headless synthetic tests passed; real Windows deformation has not been tested.
