# 032 — Relative morphology experiments

Apply over 031. No production module is changed. Refresh Experiments and run 41–48; all support automated execution and include metadata. 41 is console-only. All use private snapshots and dry runs. Use the same saved Hips value (preferably 3.98) and field mode on all comparison mods; Thighs is fixed at 2. If saved Hips is zero, the test uses 3.98. Optional post smoothing is disabled by the existing 030 isolation helper; calibration's internal filter and anatomical protections remain.

The alternatives are controlled prototypes, not a new universal engine. They retain the Rover coordinate mapping, legacy axis fitting, and legacy calibration cap and blend. Section-relative masks use maximum cross-section radii from original triangle-plane intersections; above the crotch, half-body radii can include pelvis and are not a true isolated leg radius. Missing sections are interpolated and flagged. Root fade distances are proportions of the actual model thigh length, evaluated in model Z. The target trial replaces fixed target knots with a landmark-based gain bump, not an absolute target silhouette. Local thigh trial also disables the legacy anterior amplitude override. Ownership is a distance-based soft partition of unity, not bone-weight segmentation. Dimensionless coefficients are provisional and not calibrated. The combined trial is exploratory, not a proposed production replacement.

Run on Suoming, Rover Female, and a known-good continuous-body mod. Compare contour gain, curvature, face quality, and renderings; do not judge by residual alone because target changes between some cases. 44, 46 and 47 disable calibrated hips for final application to isolate thighs. The experiment logs include the normal calibration diagnostics even in these cases; those residuals are not the residual of the final isolated thigh output.
