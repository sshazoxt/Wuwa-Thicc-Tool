# 033 — Library Experiment Automation
Run automated retains Current mod and adds Library mods via a split menu. Check desired mods; library order is preserved. Each mod is snapshotted and analyzed in an independent child process; effective configuration is archived as settings.json and used by the scripts. No original buffer, config or GUI selection is written. Incomplete analysis is reported and skips that mod. Interactive/writing experiments are excluded from automation. Each mod has its own numbered results directory, run.json, console.txt, summary.json and captures; root has aggregated console, run and summary. Cancel terminates the current subprocess and stops the queue. Snapshots are temporary; results persist. Each mod is snapshotted at its turn, not at global start. Qt/VTK integration requires Windows validation. No morphology changes.
