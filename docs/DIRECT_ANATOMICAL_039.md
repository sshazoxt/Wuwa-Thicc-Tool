# Patch 039 — Direct Anatomical Morphology Lab

Apply over patch 038. Run experiment 74 individually (interactive only). No production engine files are replaced. It starts at zero and reads the saved anatomical roles, not the Morphology slider values. A private PreviewSession uses original positions and a neutral production analysis to obtain landmarks, axes, root profiles and protections. The two direct hip modes never run the iterative hip calibration during slider changes. The neutral setup still calls the existing engine with zero calibration. Glutes, Thighs and Calves use the existing uncalibrated regional fields, without hip coupling, rounding or optional post smoothing. This does not yet replace those regional algorithms; their combined behavior can differ from production. Direct Section uses a quintic additive expansion and a provisional amplitude ratio (0.14265 times the original hip half width per unit). Direct Silhouette blends toward a Hermite target with matching endpoint slopes. The depth field is analytic and provisional. No mesh export, Apply, or modification of original files is supported. Legacy comparison is explicit and can take time; it remains frozen at the displayed values until recalculated. Diagnostics reports contour gain/curvature and triangle area/normal direction checks; these do not certify collision freedom or animation quality. The lab retains the original arm protection ramp and frozen-vertex mask, not optional garment adaptation or seam guard (isolated test configuration). The interactive window has not been tested on Windows in the authoring environment.
