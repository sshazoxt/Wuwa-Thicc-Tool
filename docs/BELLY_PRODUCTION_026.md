# 026 — Production Belly

- Install over 025. No additional dependencies. Normal Preview/Apply use the same Belly stage and persist `belly_morphology` in thicc.json. Missing settings mean zero. The four original preset amounts are unchanged; Belly is separate from them. Basic parameters are linearly interpolated from (0, 2, 1.08, -0.09) to (0.34, 2, 1.50, 0.10). Advanced is initialized from Basic on entry; returning to Basic uses the stored universal amount. Advanced depth 0..1, width 0.5..3.5, height 0.5..1.5, offset -0.15..0.10. Width is the transverse field support, not a physical width multiplier.
- Removed legacy Waist controls from production GUI. Saved legacy waist is ignored by production; diagnostic dry overrides still support old experiments. Old Waist source remains for comparisons.
- The transverse profile blends the old C2 falloff with a broader quadratic-radius C2 profile at increasing depth. The anterior gate also broadens toward the flanks. No posterior displacement, no global smoothing, no new topology. The 0.66 blend scale and width 3.5 upper limit are experimental choices, not anatomically calibrated constants. This does not remove muscular normal maps or explicitly smooth original muscle relief.
- Stage uses original active Skin cross sections with existing Region fallback, standard mobility/seam/arm restrictions and FieldComposer safety checks. Partial acceptance and bounds are logged; zero acceptance or no movable surface raises an error. Normal shading is preserved under Original; other modes transport added Belly frames using existing belly_vectors helper (Legacy uses adaptive transport for the Belly increment). Existing standard backup/restore flow is unchanged. The face test is not collision or animation validation.
- Experiment 32 still uses the old formula for independent comparison, disables production Belly in its baseline, and logs preview parameters. Experiment 33 compares Basic max, legacy high depth, rounded high depth, and expanded Width. It does not write buffers.
- Suggested UI redesign (not implemented): fixed 3D workspace, left tabs Wardrobe/Morphology/Measurements, collapsible console below, shared Preview/Apply/Restore toolbar. Preserve camera/selection when switching tabs.
- Verify in Windows with Suoming and Yangyang: Belly 0, Basic .25/.5/1, Advanced .66 width 2/2.5/3.5; inspect full body, side, front and game shading. Save/reopen mod and compare Preview/Apply, then Restore. Tests cover parameter bounds, profile symmetry/coverage, zero no-op and synthetic tube stage; no actual game buffers or Qt window were tested here.
