# Test runner 015
Place trusted Python diagnostic scripts in repository `test/` (singular). Existing `tests/` remains the automated regression suite. Click Test beside Copy and Clear, select a script. No analysis is required. Scripts run in a separate Python process with the GUI's environment, working directory `test/`, engine directory on PYTHONPATH, and stdout/stderr streamed into the diagnostic log. Environment variables: THICC_MOD_DIR, THICC_INI (empty if not found), THICC_ENGINE_DIR, THICC_TEST_DIR. Scripts receive no positional arguments. They have normal local filesystem permissions: use read-only diagnostics unless explicitly intended otherwise. No GUI state or in-memory AnalysisContext is shared. Cancel terminates the direct process. No engine or morphology algorithms changed.
