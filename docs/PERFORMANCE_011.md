# 011 — Detection performance cleanup

Normal analysis no longer runs the legacy torso, joint and independent-surface reports in `thicc_edit.run`; they are marked `DEBUG_ONLY` and preserved behind `DEBUG_LEGACY_REPORTS`. In detection002, `debug`/`verbose` gates retain the legacy shape PCA and sections, surface island inventory, whole-draw bone histograms, pair profiles, virtual complementary combinations, boundary loops and diagnostic-only signed projections. Future Debug mode must expose these flags and bypass or distinguish normal cached results; it is not implemented here. Normal console retains weighted results, ARF and the existing engine validation.

Surface RAW is skipped only if every eligible draw already has non-None ALL evidence. The existing ALL-first rule is unchanged; RAW still runs if any result is missing (provided a usable raw reference exists). Surface Relations regional proximity and bone comparisons remain because the classifier consumes them. Shape retains the area-based features and original welding precision. Welded/Shape/Surface welding tolerances differ and are not merged.

Draw triangle/vertex arrays are memoized within each engine invocation. Shape reuses Fusion's unique vertex IDs. Scoped local bone IDs are computed once for Surface; individual Stickman regional weights are evaluated only on the draw's referenced vertices, whereas global Stickman retains all vertices. Indexed connectivity now uses SciPy sparse connected components instead of Python union-find, retaining triangle-count dominance and exact-index adjacency. Welded evidence still uses its original coordinate quantization.

No change to scoring, detector order, ARF, Force analyze transaction, or deformation algorithms. Source-based cache keys invalidate previous snapshots. The debug-only metadata (e.g. surface_raw when skipped and detailed shape signatures) is intentionally absent in normal mode. Tests cover synthetic equivalence, fallback behavior, and the existing ARF/transaction tests. No real mod buffers or Windows GUI execution were available for validation. Runtime speedups on real mods must be measured separately.
