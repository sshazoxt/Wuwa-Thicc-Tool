# Regional refinement 024

Experimental only; production deformation equations unchanged. Install over 023. Run experiments 26–31 in numerical order. Each uses a private PreviewSession. 26 and 27 vary regional support height and offset (in crotch-to-knee span units), not Z coordinates. Belly width controls lateral support of anterior displacement, not direct X expansion. 28 compares actual Z displacement with XY envelope extension. 29 intentionally displays rejected trial geometry and red flagged faces; never applies it to the source. 30 compares global and sequential independent attenuation. Order matters: accepted earlier fields remain fixed; each later candidate is checked against the cumulative geometry using original normals and baseline face area. This is not a collision detector and may flag legitimate large rotations. 31 provides numeric controls and repeated Preview buttons within one session; close the comparison window to change controls. Hips baseline fixed at 2.5. Glute volume mode ignores Vertex Z; vertex mode ignores Volume height. No live slider preview. Reset restores trial defaults. Viewer focuses camera on requested Z band (not geometric clipping); keys 1–5 change views, F fits current view, W toggles wireframe, S saves PNG. Windows PyVista/PySide6 interaction requires local validation.
